# Privacy notice — DNS Zone File Tools plugin

The DNS Zone File Tools plugin runs entirely inside your IDE. It does **not** collect, store or transmit any
personal data, usage statistics, telemetry or file contents, and it makes no network connections. Links in the
quick-documentation popup open the public IANA DNS parameter registry (iana.org) in your browser only when you click them.

If you contact us through GitHub issues, GitHub's privacy policy applies to what you post there; we only use it to
answer your request.
